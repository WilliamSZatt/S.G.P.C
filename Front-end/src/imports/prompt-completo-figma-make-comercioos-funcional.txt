Crie do zero um protótipo funcional, navegável, responsivo e editável no Figma Make para o sistema web ComércioOS.

Não crie apenas imagens ou telas estáticas. Gere frames editáveis, componentes separados, textos editáveis, botões funcionais, formulários, modais, tabelas, filtros, navegação entre telas e estados de sucesso, erro, carregamento, vazio e acesso não autorizado.

O resultado deve ser um protótipo navegável para demonstração acadêmica de uma plataforma SaaS de gestão de pequenos comércios.

==================================================
1. CONTEXTO DO SISTEMA
==================================================

O ComércioOS é uma plataforma SaaS para pequenos comércios. A aplicação deve centralizar:

- Apresentação do produto;
- Cadastro do estabelecimento;
- Onboarding;
- Login;
- Recuperação de senha;
- Usuários e equipe;
- Clientes;
- Produtos;
- Estoque;
- Vendas no PDV;
- Pagamentos;
- Código de barras;
- Painel gerencial;
- Centro Fiscal demonstrativo;
- Relatórios;
- Configurações;
- Notificações;
- Suporte.

Utilize textos em português do Brasil e dados fictícios.

O comércio demonstrativo deve ser:

- Nome fantasia: Mercado & Mercearia Silva;
- Razão social: Mercado Silva Comércio de Alimentos Ltda.;
- CNPJ demonstrativo: 12.345.678/0001-00;
- Segmento: Mercado e mercearia;
- Plano: Plano Demonstrativo;
- Tenant: Mercado Silva — Loja Principal.

Nunca utilize dados pessoais reais. CPF e CNPJ devem aparecer mascarados quando exibidos em telas internas.

==================================================
3. PERFIS E CONTROLE DE ACESSO
==================================================

Utilize somente dois perfis:

A) Administrador/Gerente

O Administrador/Gerente possui acesso total ao próprio comércio e pode acessar:

- Painel;
- Vendas/PDV;
- Clientes;
- Produtos;
- Estoque;
- Centro Fiscal;
- Relatórios;
- Usuários e Equipe;
- Configurações;
- Notificações;
- Suporte.

B) Operador/Funcionário

Operador e Funcionário representam o mesmo perfil. Não crie dois perfis separados.

O Operador/Funcionário pode acessar somente:

- Vendas/PDV;
- Clientes;
- Consulta de Estoque e Produtos;
- Notificações operacionais;
- Perfil;
- Sair.

O Operador/Funcionário não pode acessar:

- Painel gerencial completo;
- Centro Fiscal;
- Relatórios administrativos;
- Usuários e Equipe;
- Configurações administrativas;
- Cadastro de produtos;
- Edição de produtos;
- Alteração de preços;
- Entrada de estoque;
- Baixa manual de estoque;
- Ajuste de estoque;
- Indicadores financeiros estratégicos.

A sidebar deve mudar automaticamente conforme o perfil.

Se o Operador tentar acessar diretamente uma rota administrativa, exibir uma tela de Acesso não autorizado com botão Voltar para Vendas/PDV.

Não crie cargos adicionais como Estoquista, Gerente de Operações, Supervisor ou Operador Sênior.

- Nova senha;

- Salvar nova senha.

==================================================
20. REGRAS DE INTERAÇÃO
==================================================

Implemente estas regras:

- Todo botão principal deve navegar ou executar uma ação simulada;
- Todo formulário deve ter validação;
- Toda ação de salvar deve exibir loading e sucesso ou erro;
- Operações destrutivas exigem confirmação;
- Listas vazias exibem orientação;
- Buscas sem resultado exibem mensagem clara;
- Erros exibem opção Tentar novamente;
- O menu muda conforme o perfil;
- O Operador não visualiza módulos administrativos;
- O Administrador acessa todos os módulos;
- O tenant Mercado Silva permanece durante a sessão;
- Os dados são fictícios;
- CPF e CNPJ aparecem mascarados;
- Código de barras é opcional no produto;
- Busca manual continua disponível no PDV;
- Venda verifica estoque antes da conclusão;
- Estoque é atualizado após venda concluída;
- Estorno exige motivo;
- Recuperação não revela se o e-mail está cadastrado;
- Link de recuperação é temporário e de uso único;
- Sair exige confirmação e volta ao Login.

21. FLUXOS OBRIGATÓRIOS
==================================================

Fluxo público:

Home → Cadastro → Onboarding → Login.

Fluxo Administrador:

Login Administrador → Painel → Clientes → Produtos → Estoque → PDV → Centro Fiscal → Relatórios → Usuários → Configurações → Sair.

Fluxo Operador:

Login Operador → Vendas/PDV → Buscar produto → Escanear ou digitar código → Carrinho → Cliente → Pagamento → Finalizar venda.

Fluxo alternativo do Operador:

Operador → Clientes → Novo cliente → Salvar → Voltar ao PDV.

Operador → Estoque → Consultar produto → Detalhes → Voltar ao PDV.

Fluxo de recuperação:

Login → Esqueci minha senha → E-mail → Verifique seu e-mail → Redefinir senha → Sucesso → Login.
